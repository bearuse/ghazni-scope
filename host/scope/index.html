User Events 태스크가 남긴 값과 글
State Machines 태스크가 알린 상태가 언제 바뀌었고 얼마나 머물렀는지 처음엔 마지막 활동 구간. 끌어서 확대, 더블클릭: 전체 기록 ↔ 마지막 활동
Memory Heap 할당기가 알린 할당·해제: 사용량 변화와 아직 해제되지 않은 블록 처음엔 마지막 활동 구간. 끌어서 확대, 더블클릭: 전체 기록 ↔ 마지막 활동
Dependency Graph 태스크가 누구를 기다리나: CALL(클라이언트 → 서버, 응답까지 기다린 시간)과 signal(보낸 태스크 → 깨어난 태스크). 선 굵기 = 횟수
Communication Flow 누가 어느 객체(큐·세마포어·mutex·이벤트 그룹, Ghazni의 endpoint·notification)에 보내거나 주고, 누가 받아 깨어났는지. 인터럽트 처리기에서 준 것은 인터럽트 이름으로 (기록 전체, 선 굵기 = 횟수)
Object History label = 메시지 레이블: 클라이언트가 보낸 요청 번호(서버가 요청 종류를 구분하는 값)
Statistics Report 인스턴스 = 준비된 때부터 다시 막힐 때까지. 실행 시간 = 그 안의 CPU 시간, 응답 시간 = 처음부터 끝까지. CPU %: 평균 = 부팅 뒤 전체, 구간 = 보이는 구간(Trace View), 지금 = 최근 0.1초 (코어 하나 = 100 %). 커널 시간 = CPU 시간 가운데 커널이 그 태스크의 시스템 콜·폴트를 처리한 시간(Ghazni만; FreeRTOS는 –). PI 상속 = 우선순위를 물려받은 횟수 구간 비교:
